# Checklist de datos y permisos para la tienda

Todo comienza pendiente. Marca únicamente lo recibido o comprobado; no rellenes
faltantes con estimaciones presentadas como reales.

- [ ] Dueño/encargado autoriza alcance, uso, acceso y conservación de la copia.
- [ ] Permisos separados para exportación, fotografías, red, electricidad y sensores.
- [ ] Tres problemas prioritarios y una línea base medible.
- [ ] 10–20 productos con código estable, nombre, presentación y unidad base.
- [ ] Equivalencia unidades/caja y kg por unidad para cada producto.
- [ ] Mapa de almacén, zonas, racks, niveles y capacidad kg.
- [ ] Conteo físico por ubicación con fecha/hora y responsable por rol.
- [ ] Saldo del sistema y diferencia frente al conteo físico.
- [ ] Reservas, dañados, vencidos y stock no vendible separados.
- [ ] Mínimos/máximos reales; no confundir máximo con capacidad física.
- [ ] Lotes y vencimientos fotografiados solo con autorización o transcritos.
- [ ] Proveedor, frecuencia de compra, cantidad y plazo de entrega separados.
- [ ] Pedidos pendientes y ejemplos de compras/recepciones.
- [ ] Exportación diaria de ventas por producto, fecha y unidades.
- [ ] Meses disponibles; días cerrados, sin datos, sin stock y promociones identificados.
- [ ] Devoluciones y estimaciones de ventas perdidas separadas de ventas.
- [ ] Roles para registrar productos, recibir, vender, contar y aprobar.
- [ ] Sin contraseñas personales, datos de clientes ni medios de pago en archivos.
- [ ] IoT: variable, unidad, ID, ubicación, alimentación y Wi-Fi autorizados.
- [ ] Límites con fuente, responsable y acción al sobrepasarlos; sin inventar umbrales.
- [ ] Copia original intacta, copia de trabajo y correspondencia SKU → id_producto.
- [ ] Distinción visible entre REAL y SIMULADO en cada archivo y demostración.
- [ ] Saldo final conciliado y comentarios del dueño registrados.
- [ ] Fecha, responsable y condiciones de la siguiente prueba acordados.

Formato de control sugerido: dato | recibido/pendiente/no aplica | responsable |
fuente/archivo | fecha | observaciones. Usa el diccionario completo de la
[guía de visita](GUIA_VISITA_TIENDA_PSITWIN.md).
